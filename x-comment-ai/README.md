# X Comment AI

Paste any X (Twitter) post link → get **3 perfect, engaging replies** generated by **Groq + Llama 3.3** in seconds.

- **Backend:** FastAPI (async)
- **LLM:** Groq API (`llama-3.3-70b-versatile` by default)
- **Scraper:** [`twscrape`](https://github.com/vladkens/twscrape)
- **Frontend:** Jinja2 + Tailwind (CDN) + vanilla JS
- **Theme:** Dark, glassmorphic, mobile-first

## Features

- 3 reply variants generated in parallel (different temperatures for diversity)
- Tone selector — *witty / supportive / sarcastic / insightful / hype*
- Length selector — *short / medium / long*
- Regenerate button (re-rolls without re-scraping)
- Live X character counter (warns past 240, danger past 280)
- Edit-in-place — every variant is a `contenteditable` block
- One-click "Reply on X" deep-link (opens X compose with the edited text)
- One-click Copy to clipboard (with fallback for non-secure contexts)
- Recent history stored in `localStorage` (last 10 generations)
- Auto-paste from clipboard when focusing the empty URL field
- `Cmd/Ctrl + Enter` submits from anywhere
- Bilingual prompt (Bengali + English + Banglish)

## 1. Prerequisites

- **Python 3.10+** (3.11 recommended)
- A **Groq API key** — https://console.groq.com/keys
- **At least one X account** (a throwaway is recommended) for `twscrape`

---

## 2. Clone & install

```bash
git clone https://github.com/<your-username>/x-comment-ai.git
cd x-comment-ai

python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate

pip install --upgrade pip
pip install -r requirements.txt
```

---

## 3. Configure environment

```bash
cp .env.example .env
```

Edit `.env`:

```env
GROQ_API_KEY=gsk_your_real_key_here
GROQ_MODEL=llama-3.3-70b-versatile
TWSCRAPE_DB_PATH=accounts/accounts.db
```

---

## 4. Add a `twscrape` account

```bash
twscrape add_accounts accounts.txt username:password:email:email_password
twscrape login_accounts
twscrape accounts          # verify active=True
```

`accounts.txt` format (one per line):

```
username:password:email:email_password
```

> Use a Gmail **App Password** (not your real password) so twscrape can read login codes.

The `accounts.db` is created in `accounts/` — it contains cookies, **never commit it**.

---

## 5. Run

```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
# or:
./run.sh
```

Open http://localhost:8000.

## 7. API

### `POST /generate`

```json
{
  "url": "https://x.com/elonmusk/status/1234567890",
  "lang": "auto",
  "tone": "witty",
  "length": "medium",
  "n": 3
}
```

Response:

```json
{
  "url": "...",
  "tweet_id": "1234567890",
  "author": "@elonmusk",
  "author_name": "Elon Musk",
  "original": "...",
  "thread": ["..."],
  "variants": ["reply 1", "reply 2", "reply 3"]
}
```

### `POST /regenerate`

Re-uses the previously fetched tweet content (no scrape):

```json
{
  "original": "...",
  "thread": ["..."],
  "lang": "auto",
  "tone": "sarcastic",
  "length": "short",
  "n": 3
}
```

### Error format

```json
{ "detail": "Human-readable error message" }
```

| HTTP | Meaning |
|------|---------|
| 400  | Invalid URL / could not parse a tweet ID |
| 404  | Tweet not found (deleted, private, rate-limited) |
| 502  | Scraper or Groq API failure |
| 503  | No active twscrape accounts, or `GROQ_API_KEY` missing |

---

## 8. Production tips

- Run with `--workers 1` or `--workers 2` to avoid scraping rate limits (each worker maintains its own connection pool but they share `accounts.db`).
- Put Nginx (or Caddy) in front and terminate TLS there.
- Keep 3–5 twscrape accounts; the library auto-rotates them.
- Mount `accounts/` and `.env` as volumes if running in Docker.

## 9. Troubleshooting

| Problem                                       | Fix                                                                 |
|-----------------------------------------------|---------------------------------------------------------------------|
| `No active twscrape accounts`                 | Re-run `twscrape login_accounts`. Check `twscrape accounts`.        |
| Login keeps failing with `EmailLoginRequired` | Use a Gmail **App Password** in the email field.                    |
| `GROQ_API_KEY is not set`                     | Confirm `.env` exists and uvicorn was restarted after editing it.   |
| `Tweet not found`                             | Tweet deleted/private, or your account is rate-limited.             |
| Replies sound robotic                         | Try `llama-3.3-70b-versatile` and bump temperature to 0.9.          |
| 429 from Groq                                 | Free-tier rate limit — wait a minute or upgrade.                    |
